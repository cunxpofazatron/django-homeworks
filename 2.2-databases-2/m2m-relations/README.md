# Задание 2.2 — Many-to-Many Relations (новостной сайт с тематическими разделами)

## Что сделано

- Созданы три модели:
  - `Tag` — тематические разделы (теги)
  - `Article` — статьи с заголовком, текстом, изображением и датой публикации
  - `Scope` — промежуточная таблица для связи многие-ко-многим между статьями и тегами, содержит поле `is_main` (основной раздел)

- Реализована связь ManyToManyField через промежуточную модель (`through='Scope'`)
- В админке Django:
  - Можно создавать/редактировать теги и статьи
  - При редактировании статьи можно назначать несколько тегов
  - Обязательна проверка: у каждой статьи должен быть **ровно один основной тег** (`is_main=True`)
  - Если условие нарушено — сохраняется ошибка при попытке сохранить статью

- В представлении (`views.py`) реализована логика сортировки тегов:
  - Основной тег отображается первым
  - Остальные теги сортируются по алфавиту

- Шаблон (`templates/articles/news.html`) отображает новости с тегами в виде бейджей:
  - Основной тег — синий (`badge-primary`)
  - Дополнительные — серые (`badge-secondary`)

- Загружены тестовые данные из `articles.json`

> ⚠️ Примечание: файл `query.py` был использован на начальном этапе, но основная функциональность теперь доступна через веб-интерфейс и админку.

## Пример работы

На главной странице http://127.0.0.1:8000/ отображаются новости с тегами:

### Статья 1: "В 'Детском мире' на Лубянке откроют музей"
- 🔵 Культура (основной)
- ⚪ Город

### Статья 2: "Ученые доказали вред периодического курения"
- 🔵 Здоровье (основной)
- ⚪ Наука

### Статья 3: "Директор ИКИ РАН прокомментировал инициативы по созданию базы на Луне"

- ⚪ Международные отношения
- ⚪ Наука *(отсортировано по алфавиту)*
